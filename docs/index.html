Voir ce qui se passe, en direct

La surveillance trace le processeur, la mémoire et le débit réseau sur les dernières minutes. Les alertes préviennent par une notification quand un seuil est dépassé.

  • Courbes avec infobulle au survol
  • Seuils réglables pour le processeur, la mémoire, le disque et la température
  • Historique conservé pour suivre les tendances

Savoir quel logiciel pose problème

L'écran Processus classe les programmes les plus gourmands, trace l'historique de celui que vous sélectionnez et permet de le suspendre, le terminer ou changer sa priorité.

  • Graphiques système et classements processeur et mémoire
  • Actions protégées : jamais le processus système, jamais l'application elle-même
  • Origine de chaque processus (service, session, paquet)

Repérer ce qui sort de l'ordinaire

Le scan des comportements anormaux examine les logiciels en cours d'exécution et ce qui les relance. Il explique chaque constat et propose une réponse : suspendre, terminer, mettre en quarantaine.

  • Programmes lancés depuis /tmp, exécutables supprimés, noms de mineurs
  • Scripts de démarrage douteux (curl | sh, shell inversé…)
  • Fichiers setuid, comptes anormaux, outils à double usage
Ce n'est pas un antivirus. L'analyse est heuristique, sans base de signatures : un constat est un indice à vérifier, pas une preuve. ClamAV peut être lancé en option.
Confiance

Une application d'administration doit être prévisible

Elle touche à des choses sensibles. Voici ce qu'elle s'interdit.

Jamais de shell

Les commandes sont lancées avec une liste d'arguments, jamais par concaténation de texte. Noms de paquets, d'unités, chemins et adresses sont validés avant tout appel.

Confirmation et Polkit

Toute action destructrice demande une confirmation. Les opérations privilégiées passent par pkexec : le système demande votre mot de passe administrateur.

Lecture seule par défaut

Les écrans d'analyse (audit, matériel, scan, stockage) ne modifient rien. La quarantaine déplace un fichier sans le supprimer, et retire ses droits d'exécution.

Audité et testé

Un audit de sécurité du code a été mené et ses corrections appliquées (fichiers temporaires privés, secrets hors des arguments, contrôle des archives). 347 tests automatiques vérifient parseurs, validations et protections.

Le détail des règles est dans la documentation développeurs.

Installer

Une commande, c'est tout.

Téléchargez le paquet pour votre distribution, puis :

orbisys_1.0.0_amd64.deb · 3,6 Mo

Téléchargez le paquet pour votre distribution, puis :

orbisys-1.0.0-1.x86_64.rpm · 4,5 Mo

Téléchargez le paquet pour votre distribution, puis :

orbisys-1.0.0-1-x86_64.pkg.tar.zst · 3,6 Mo

Téléchargez le paquet pour votre distribution, puis :

orbisys-1.0.0-r0.apk · 4,6 Mo

Il faut Rust 1.80 ou plus récent (rustup.rs).

À l'exécution, l'interface utilise Wayland ou X11. Aucune bibliothèque Qt n'est nécessaire.

Désinstaller OrbiSys

Supprimez OrbiSys avec la commande correspondant à votre distribution :

DistributionCommande
Ubuntu / Debiansudo apt remove orbisys
Fedora / RHELsudo dnf remove orbisys
openSUSEsudo zypper remove orbisys
Arch Linuxsudo pacman -R orbisys
Alpine Linuxsudo apk del orbisys

Si vous avez compilé depuis les sources, fermez OrbiSys puis supprimez le dossier du dépôt.

Si vous aviez ajouté le PPA, retirez-le séparément :

sudo add-apt-repository --remove ppa:amine-elharrak/ppa
